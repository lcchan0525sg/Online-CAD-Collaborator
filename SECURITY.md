# Security policy

## Supported versions

Security fixes are applied to the latest released version and the current development branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email the maintainer privately with:

- a clear description and impact;
- reproducible steps or a minimal proof of concept;
- affected version or commit; and
- any suggested mitigation.

The maintainer will acknowledge the report, investigate it, and coordinate a fix before public disclosure when appropriate.

## Deployment note

Online CAD Collaborator is intended for trusted local-network or controlled deployments. Anyone who can reach the server may be able to join or interact with a shared session. Put the server behind appropriate network controls before exposing it beyond a trusted network.
