## 1. 欢迎使用

![GearBox 齿轮箱装配体的三维展示](manual-shots/17-hero.png)

**把 CAD 文件变成可以共同查看和操作的实时三维场景。** Online CAD Collaborator 是一款在浏览器中运行的实时协作 CAD 查看器。同一网络内的其他人只需打开浏览器，即可查看共享模型，无须安装 CAD 软件或购买 CAD 软件许可证。会话成员可以同步观察并操作模型。

### 功能概览

| 常见工作方式 | 使用本应用后 |
|---|---|
| 导出、发送邮件、等待对方打开，再重复沟通 | 分享一个加入链接，在同一场景中讨论 |
| 发送较大的 CAD 文件包 | 先转换成适合浏览器显示的 GLB/GLTF，再共享 |
| 依靠静态截图解释问题 | 在实时模型上一起选择、移动、测量和缩放 |
| 要求访客安装 CAD 软件 | 访客使用现代浏览器打开链接即可 |
| 向访客分发模型文件 | 应用将模型传送到访客浏览器内存中显示，不主动保存模型文件到访客磁盘 |

### 应用功能

- **Windows 便携版：** 下载 ZIP、解压，然后双击 `start.bat` 即可启动，无须另外安装 Node.js 或 npm。
- **主持人与访客都能操作：** 会话不是单向演示。成员可以环绕、缩放和平移视图，显示或隐藏零件，选中零件，沿 X/Y/Z 移动零件，测量距离并聊天。
- **实时同步：** 相机、零件可见性、选中状态、移动、测量、透明度、爆炸视图以及灯光和动画等状态可以在成员之间同步。稍后加入的成员会收到当前模型和视图状态。
- **测量与检查：** 选择零件上的两个角点读取距离，并在会话聊天中记录意见。
- **访客无须安装：** 访客只需浏览器和可访问的会话链接，无须安装转换运行环境。
- **内存中查看：** 应用不主动把共享模型另存为访客磁盘上的文件；关闭页面后不再显示该模型。这并不阻止接收者截图或提取已接收的数据，共享时仍应选择可信人员。
- **高效共享：** 服务器将 STEP、IGES 和 STL 转换为适合网页显示的 GLB/GLTF，减少反复分发原始 CAD 文件的需要。
- **跨平台查看：** 可使用 Windows、macOS、Linux 和平板上的现代浏览器。支持的转换尽量保留零件名称、颜色和材质；Windows 便携启动包与浏览器访客的平台要求不同。

### 可以解决什么问题

在同一个实时视图中开展工程设计评审和校核：通过共同指认、测量和观察实际几何形状，减少来回导出文件和邮件沟通。

### 适用场景

- **设计评审与确认：** 跨办公室或车间共同审阅模型。
- **远程检查：** 在制造前检查零件或装配关系。
- **实时位置讨论：** 移动零件时，其他成员立即看到变化。
- **客户演示：** 客户无须安装 CAD 软件即可观看设计。
- **供应商与分包商沟通：** 制造前共同核对几何形状、配合关系和公差要求。
- **跨地点校核：** 在不同地点将实物与共享模型进行对照。

## 2. 启动应用程序

### Windows 便携版：下载、解压、运行

1. [下载 `cad-viewer-portable-v1.047.zip`](https://github.com/lcchan0525sg/Online-CAD-Collaborator/releases/download/v1.047/cad-viewer-portable-v1.047.zip)。其他版本请查看 [GitHub Releases](https://github.com/lcchan0525sg/Online-CAD-Collaborator/releases)。
2. 将 ZIP **完整解压到电脑上的文件夹**，不要直接在压缩包内运行程序。
3. 打开解压后的应用文件夹，双击 **`start.bat`**。启动器会在可用时选用随包提供的本机 OpenCascade/OCP 环境，并打开浏览器。
4. 默认访问 **<http://localhost:8088/>**。如果浏览器没有自动打开，请手动输入该地址；若页面打开早于服务启动完成，请稍后刷新。

便携包包含 Node 运行环境和依赖，无须另外安装 Node.js 或 npm。使用期间请保持启动窗口运行。

### 从源代码启动

先按 [README](../README.md#run-from-source) 安装依赖。可以双击仓库中的 `start.bat`，自动查找 `%USERPROFILE%\venvs\cad-native\Scripts\python.exe`；也可以配置 `CAD_PYTHON` 后运行 `npm start` 或 `node src/server.js`。

### 更改端口

默认端口为 **8088**。

| 方法 | 示例 |
|---|---|
| 为便携版启动器传入参数 | `start.bat 5555` |
| 在启动器旁创建 `port.txt` | 文件内容写为 `5555` |
| 从源代码启动时设置环境变量 | Windows：先执行 `set PORT=5555`，再执行 `npm start`；macOS/Linux：`PORT=5555 npm start` |

**当前 Windows 便携版启动器的优先级：`port.txt` → 命令行参数 → 默认 8088。** 启动器会设置 `PORT`，因此不要依赖启动前设置的 `PORT` 来覆盖便携版端口。如果参数没有生效，请检查同目录的 `port.txt`。

更改端口后，访问相应地址，例如 `http://localhost:5555/`。加入链接和 `/ip` 返回的信息使用实际服务端口。

### 更改界面语言

查看器默认使用英语。在三维视图右上方打开 **View（视图）** 浮动面板，通过 **Language（语言）** 选择器选择可用的 **繁體中文** 或 **简体中文**。浏览器会记住选择；缺失或无效的翻译使用英文回退。

中文界面依赖外部 UTF-8 JSON 语言包。源代码方式运行时，将 `CAD_LANGUAGE_DIR` 指向包含 `zh-Hant.json` 和 `zh-Hans.json` 的文件夹；便携版将经审核的语言文件放在 `server.js` 旁的 `languages/` 文件夹中。未提供有效语言包时，界面保持英文。验证和打包方法见 [翻译工作流程](TRANSLATION-WORKFLOW.md)。本中文手册本身不会改变应用的界面语言。

### 本机 CAD 转换环境：OpenCascade/OCP 7.9.3

STEP、IGES 和 STL 的内置转换需要本机 OpenCascade/OCP 运行环境。源代码部署可使用包含 `cadquery-ocp` 7.9.3.1.1 的 Windows Python 环境；访客无须安装该环境。

`start.bat` 会自动查找常用的 `%USERPROFILE%\venvs\cad-native` 路径。使用其他环境时，在 Windows 命令提示符中执行：

```bat
set CAD_PYTHON=C:\Users\you\venvs\cad-native\Scripts\python.exe
node src\server.js
```

GLB/GLTF 的显示本身不需要 CAD 转换；但当前服务器启动时会预检 `import OCP`，本机运行环境不可用时会拒绝启动。请按启动窗口提示配置环境。健康检查后，模型面板会显示本机转换后端信息。

![刚启动时尚未打开模型的空白视图](manual-shots/01-empty-start.png)

## 3. 打开模型

1. 点击左侧的 **Open model…（打开模型）**。
2. 从电脑中选择 `.glb`、`.gltf`、`.step`、`.stp`、`.igs`、`.iges` 或 `.stl` 文件。

GLB/GLTF 可以直接加载。STEP、IGES 和 STL 会先在服务器端通过 OpenCascade 转换为 GLB；处理期间会显示进度遮罩，耗时取决于模型大小和复杂程度。

![已加载的模型及信息、装配和材质面板](manual-shots/02-model-loaded.png)

模型相关面板包括：

- **Info（信息）：** 生成工具、网格和三角形数量、尺寸及单位。
- **Assembly / Parts（装配 / 零件）：** 装配树，见[第 4 节](#section-4)。
- **Materials（材质）：** 模型中使用的颜色样本。

<a id="section-4"></a>
## 4. 装配面板：零件与可见性

模型的零件显示在三维视图左侧浮动面板的 **Parts（零件）** 树中。初始展开到第 2 层，即顶层装配及其直接子项；更深的层级可手动展开。旧版截图中的装配树可能位于侧栏。

![显示装配层级的零件树](manual-shots/03-assembly-panel.png)

### 展开与折叠

- 含有子项的行左侧显示 **+/−** 开关。
- 点击 **+** 展开子项，点击 **−** 折叠子项。
- 展开与折叠只改变树的显示方式，不改变三维零件的可见性。

### 显示与隐藏零件

- 每个零件都有复选框：取消勾选可隐藏，勾选可显示。
- 操作父项会应用到整个子树；显示子装配时，其子项也会重新显示。渲染零件需要其上级层级保持可见。
- **Show all / Hide all（全部显示 / 全部隐藏）** 对整个模型生效。

### 筛选零件树

在 **Filter parts…（筛选零件）** 输入框中输入名称，列表只显示匹配零件及其上级路径。清空输入框可恢复完整树。筛选只作用于当前浏览器，不改变零件可见性或其他成员的视图。

### 选中并高亮零件

点击树中的零件名称，或在三维视图中用鼠标左键点击零件，即可将其高亮为蓝色。点击另一个零件可切换选择；再次点击同一零件或点击空白区域可清除选择。高亮不会影响使用相同原始材质的其他零件。

![在树中选中零件后，三维视图中的零件变为蓝色](manual-shots/12-part-selected.png)

![直接点击三维零件也可选中并高亮](manual-shots/14-part-selected-3d.png)

### 悬停显示名称

将鼠标停在三维零件上，指针旁会显示零件名称提示，装配树中的对应行也会高亮。环绕、平移或缩放时会暂时停止悬停提示，操作结束后再次移动鼠标即可恢复。

![悬停时显示零件名称](manual-shots/22-part-hover.png)

### 右键菜单

在树中的零件名称或视图中的零件上点击右键，可使用以下操作：

| 操作 | 作用 |
|---|---|
| **Hide part（隐藏零件）** | 隐藏该零件及其子树 |
| **Move part（移动零件）** | 选中该零件并启用移动轴控件，见[第 5 节](#section-5) |
| **Show me only（仅显示此项）** | 隐藏其他零件，仅保留该零件及其子项；上级节点保持可见，以便正常渲染 |
| **Make transparent（设为透明）** | 以 16% 不透明度显示；已透明时菜单改为 **Make opaque（恢复不透明）**，见[第 8 节](#section-8) |
| **Comment…（评论）** | 打开输入框，输入意见后点击 **Send（发送）**，以 `[零件名称] 评论内容` 的形式发到会话聊天；需要先加入会话 |

![包含仅显示此项的右键菜单](manual-shots/13-show-me-only-menu.png)

## 5. 移动与旋转零件

通过交互工具栏和三维轴控件，可以沿 X、Y、Z 轴移动选中的零件，或绕轴旋转。工具栏也提供旋转中心和测量工具。

![交互工具栏、零件树、移动轴控件及零件操作](manual-shots/24-moving-rotating-ui.png)

### 开始移动

1. 点击装配树中的名称，或直接点击三维零件，选中要移动的零件。
2. 点击交互工具栏中的 **Move（移动）**，显示轴控件。
3. 点击工具栏中的 **X / Y / Z** 或对应轴箭头，选择移动轴；当前轴会高亮。

也可以右键点击零件，选择 **Move part（移动零件）** 进入同一模式。

### 拖动移动

选好轴后，在视图中按住鼠标左键拖动，零件会沿该轴移动，同级的其他零件保持原位。按 **Esc** 可取消当前操作。每次完成拖动都会记录为一个撤销步骤。

### 轴控件

X、Y、Z 箭头分别为红、绿、蓝色，在不同缩放比例下保持约为屏幕尺寸的 1/8。已启用的轴更亮；工具栏状态文字显示当前模式和轴。

### 撤销、重做与重置

变换历史包含移动、旋转及自定义旋转中心的调整，最多保留 200 步。

- **Undo（撤销）：** 撤回最近一次变换。
- **Redo（重做）：** 重新应用刚撤销的变换。
- 快捷键：**Ctrl+Z** 撤销，**Ctrl+Y** 或 **Ctrl+Shift+Z** 重做。
- 撤销后开始新变换，会清除重做历史。
- **Reset（重置）：** 将全部零件恢复到初始位置，收起爆炸视图，并清空历史。

在会话中，撤销和重做会把完整变换同步给其他成员。如果其他人已修改同一零件，过期的撤销或重做会被拒绝，避免覆盖较新的操作，并提示修改者，例如“无法撤销：Bob 已更改此零件”。其他成员移动或旋转当前选中零件时，也会显示其姓名提示。

### 旋转零件

1. 选中零件，使用工具栏 **Rotate（旋转）**，或先通过 **Move part** 启用轴控件。
2. 点击 X/Y/Z 轴箭头，或按 **X / Y / Z**，选择旋转轴；垂直于该轴的平面上会显示带箭头的半圆弧。
3. 按 **R** 或点击圆弧箭头启用旋转，圆弧会发亮。
4. 按住鼠标左键沿圆弧拖动，绕该轴旋转零件。

旋转与移动共用撤销及重置功能。在会话中，零件移动和旋转都会同步给所有成员，其他成员也可以继续操作。

### 自定义旋转中心

通过 **Pivot（旋转中心）** 工具，可以把旋转中心移到零件自身中心以外的位置。

1. 选中一个零件。
2. 选择 **Pivot**，将十字标记拖到所需位置。
3. 选择 **Rotate**，启用一个轴并拖动旋转圆弧。
4. 点击选中零件工具栏中的 **Reset pivot（重置旋转中心）**，恢复默认中心。

旋转中心包含在变换历史中，并与零件位置和旋转一起同步。模型加载期间，每个零件会记住自己的旋转中心。**Reset pivot** 只清除选中零件的设置；全局 **Reset** 清除所有旋转中心；重新加载模型也会清空这些设置。

### 交互工具栏

工具栏提供 **Select（选择）**、**Move（移动）**、**Rotate（旋转）**、**Pivot（旋转中心）** 和 **Measure（测量）**，并显示当前轴、下一步操作、完成或取消反馈以及选中零件的相关操作。按 **Esc** 取消当前交互。

## 6. 测量距离

**Measure（测量）** 工具读取两个零件角点之间的距离，默认单位为毫米，适合评审时检查尺寸。

![两个角点之间的距离测量](manual-shots/20-measure.png)

### 测量步骤

1. 启用 **Measure**。旧版面板使用测量复选框，新版可从交互工具栏选择；测量与零件移动模式互斥。
2. 将鼠标移近零件角点，琥珀色标记会吸附到角点，并显示实时读数。
3. 先点击第一个角点，再点击第二个角点。两点间会出现尺寸线，并加入测量列表。

### 测量列表

每条记录显示距离及仰角、P1/P2 的坐标和方位角。默认距离和坐标单位为 mm，可切换为 in。

点击记录旁的 **✕** 删除单条测量，点击 **Clear（清空）** 删除全部。按 **Esc** 取消尚未完成的选点。

> **角点吸附：** 工具吸附到零件的角点或锐边特征，而不是面上的任意位置。

已完成的测量会同步到会话中的所有成员，后来加入的成员也能看到已有测量。

### 尺寸标注

每条已完成的测量在三维视图中显示带双端箭头的 CAD 风格尺寸线，以及位于线段中点旁的距离标签。标签使用当前 mm/in 单位，并带有深色描边。

标注始终朝向相机；环绕、缩放和平移时会重新投影，保持与测量角点对应。

<a id="section-7"></a>
## 7. 爆炸视图

**Explode（爆炸）** 将装配体的零件分开，便于查看装配关系。

![分开显示的装配零件](manual-shots/18-explode.png)

### 控件

- **Explode 滑块：** 从 **0 mm**（装配状态）逐渐增加间距，分离所选装配的直接子项。
- **Dir（方向）：** 选择世界坐标系的 **X / Y / Z** 轴；位于正方向的零件向正方向移动，负方向的零件向负方向移动。
- **Scope（范围）：** 在零件树中选择一个装配，分离其直接子项。未选择时使用默认顶层装配；选择叶子零件时保留上一个有效装配范围。
- 范围信息显示装配名称、子项数量、间距和方向。

该操作不破坏原始装配位置。点击 **Explode Reset（重置爆炸视图）** 可恢复零件原位；需要重新把整个模型放入视野时，另行点击 **Frame（适配视图）**。

在会话中，任何成员调整爆炸视图，其他成员都会同步看到变化。

<a id="section-8"></a>
## 8. 零件透明度

将零件设为透明，可以观察外壳、盖板后方的结构和零件嵌套关系。

1. 在树中或三维视图中右键点击零件。
2. 选择 **Make transparent（设为透明）**，零件以 16% 不透明度显示。
3. 再次右键点击并选择 **Make opaque（恢复不透明）** 即可恢复。

![外层零件透明后可看到后方结构](manual-shots/19-transparent.png)

透明零件仍可选中、移动和测量，不会因选中而恢复不透明。会话中的透明度状态会同步给所有成员。

<a id="section-9"></a>
## 9. 操作三维视图

| 操作 | 效果 |
|---|---|
| 鼠标左键拖动 | 环绕模型；在移动或测量等工具启用时，按当前工具模式操作 |
| 滚轮 | 缩放 |
| 鼠标右键拖动 | 平移 |
| **Frame model（适配模型）** | 调整视图，使模型完整显示 |
| **Wireframe overlay（线框叠加）** | 显示或隐藏全部零件的线框 |
| **Grid（网格）** | 显示或隐藏地面网格 |
| **Auto-rotate（自动旋转）** | 缓慢旋转展示；会话中禁用 |

### 预设视角

视图右上角的 **View（视图）** 面板提供标准相机方向：

| 按钮 | 视角 |
|---|---|
| **Iso** | 等轴测视图，即默认斜视角 |
| **Front / Back** | 前视 / 后视，沿模型 Z 轴观察 |
| **Left / Right** | 左视 / 右视，沿模型 X 轴观察 |
| **Top / Bottom** | 顶视 / 底视，垂直向下或向上观察，并校正画面朝上方向 |

每个预设都会从相应方向适配模型，会话中的其他成员也会跟随相机变化。

同一面板中的 **📷** 按钮将当前画面下载为 PNG 图片，文件名为 `cad-view-<timestamp>.png`。截图仅在本地下载，不会自动发送到会话中，可用于聊天、笔记或评审记录。

<a id="section-10"></a>
## 10. 剖切视图

**Section（剖切）** 工具使用平面裁切模型，便于观察外壳内部、通道和装配体中的零件位置。可在模型控制区域找到该工具。

| 控件 | 作用 |
|---|---|
| **Section** 复选框 | 开启或关闭剖切 |
| **Axis（轴）** | 选择剖切平面朝向 X、Y 或 Z |
| **Offset（偏移）** | 沿所选轴移动剖切平面，使用当前单位显示 |
| **Reverse（反向）** | 改为保留平面的另一侧 |
| **Reset（重置）** | 关闭剖切并恢复完整模型 |

### 剖切平面辅助显示

开启剖切后，视图显示半透明蓝色平面，以及平面与可见零件表面相交形成的橙色轮廓线。

拖动 **Offset** 滑块时，平面和轮廓实时移动，可逐步扫描模型内部。辅助图形仅用于指示位置，实际几何裁切由剖切平面执行。

### 保存剖切预设

在 **Name this cut…（为此剖切命名）** 输入名称，点击 **Save cut（保存剖切）** 或按 Enter。保存项显示在控件下方；点击可恢复对应轴和偏移，点击 **✕** 删除。当前预设会高亮。

预设在会话中共享，所有成员可以使用相同的命名剖切。加载新模型时会清空预设。

### 导出二维剖面图

**Export SVG** 和 **Export PNG** 将当前橙色剖面轮廓投影到剖切平面，按当前 mm/in 单位导出二维图：

- **SVG：** 可缩放的矢量图，适合打印或在 CAD / 绘图工具中继续标注。
- **PNG：** 栅格图片，适合粘贴到笔记或聊天中。

导出图包含类似 `Section Y · 60 mm` 的标签。导出仅在当前浏览器进行，不会自动发送到会话。

<a id="section-11"></a>
## 11. 模型校正：单位、比例、镜像与旋转

三维视图左下方的 **Model（模型）** 浮动面板默认折叠，点击标题可展开。无须重新从 CAD 导出，即可调整模型的显示方式。

| 控件 | 作用 |
|---|---|
| **Units（单位）** | 在 **mm（毫米）** 与 **in（英寸）** 间切换，影响测量距离、点坐标和剖切偏移的读数 |
| **Scale（比例）** | 在自动缩放基础上使用 **0.1×–10×** 倍率校正比例；**Reset** 恢复为 1× |
| **Flip（镜像）** | 沿 X、Y 或 Z 轴镜像模型 |
| **Rotate（旋转）** | 选择轴及角度（度），点击 Rotate 旋转整个模型 |
| **Reset corrections（重置校正）** | 一次清除比例、镜像和旋转校正 |

这些校正在会话成员之间共享，后来加入的成员也会收到当前设置。

<a id="section-12"></a>
## 12. 灯光与动画

### 灯光

在 **Lighting（灯光）** 区域调整模型照明：

| 控件 | 作用 | 范围 | 默认值 |
|---|---|---|---|
| **Ambient（环境光）** | 来自天空和地面的均匀补光 | 0–2 | 0.9 |
| **Key（主光）** | 产生阴影的主要方向光 | 0–6 | 2.4 |
| **Fill（补光）** | 来自另一侧的冷色补光 | 0–3 | 0.6 |
| **Front（正面光）** | 从观察者方向照射，适合改善正面过暗的情况 | 0–3 | 0（关闭） |

拖动滑块可实时查看效果。**Reset lighting（重置灯光）** 恢复默认值。

### 动画

如果 GLB 包含关键帧动画，例如从 Blender 导出的动画，会显示 **Animation（动画）** 区域。由 STEP/IGES/STL 转换得到的 CAD 模型不包含此类动画。

| 控件 | 作用 |
|---|---|
| **Play / Pause（播放 / 暂停）** | 开始或停止播放 |
| **Loop（循环）** | 重复播放；关闭时播放一次后停止 |
| **Speed（速度）** | 播放速度为 0.25×–4× |
| **Clip（片段）** | 模型包含多个动画片段时选择一个 |

### 会话同步

灯光强度和动画状态（片段、播放/暂停、循环、速度）会同步给其他查看者，后来加入者也会收到当前设置。相机、零件可见性、装配树展开/折叠、选择、零件移动、测量、透明度和爆炸视图也会同步，见[第 14 节](#section-14)。

<a id="section-13"></a>
## 13. 创建协作会话：主持人

会话让局域网中的其他人查看同一模型，并共享相机和零件状态。

启动时按提示输入姓名，成员列表会显示该姓名及角色，例如 `Alice · host` 或 `Bob (you)`。浏览器会记住姓名。

1. 点击 **Create session（创建会话）**，生成一个 5 字符会话码。
2. 打开模型，或重新共享已经加载的模型。
3. 将会话码下方的 **加入链接**，或会话码本身，发送给其他用户。

![创建会话后显示会话码和局域网加入链接](manual-shots/04-session-created.png)

向访客传送模型时，会显示 **Sending model to guest(s)…（正在向访客发送模型）** 遮罩；所有已连接访客确认接收后恢复操作。

![主持人发送模型时的提示](manual-shots/06-sending-overlay.png)

会话码下方的成员列表显示已连接人员。主持人可点击姓名旁的 **kick（移除）** 移除访客；访客的共享视图会清空，并提示被主持人移除。**Share session** 旁的状态点指示服务器连接情况：绿色为可用，红色为不可用。

![主持人的成员列表中显示已连接访客](manual-shots/05-host-roster.png)

创建或加入会话后，聊天窗口会自动打开，见[第 15 节](#section-15)。

<a id="section-14"></a>
## 14. 加入会话：访客

在同一网络内的另一台电脑上，打开主持人发送的加入链接；或者打开服务器上的应用，在 **session code（会话码）** 中输入代码并点击 **Join（加入）**。访客应使用主持人的网络地址，而不是自己电脑的 `localhost`。

接收期间显示 **Receiving model…（正在接收模型）** 和字节进度；完成后会显示与主持人相同的模型、视角和零件可见性。

![访客接收到共享模型后的视图](manual-shots/07-guest-received.png)

### 同步内容

- **相机：** 任意成员环绕、缩放或平移时，其他成员跟随。
- **零件可见性：** 显示或隐藏零件会对所有成员生效。
- **零件变换：** 移动、旋转和旋转中心更新会同步。
- **测量：** 已提交的尺寸标注会显示给所有成员。
- **透明度与爆炸视图：** 各成员保持相同状态。
- **模型本身：** 后加入者自动接收当前模型和可见性状态。
- **展开、折叠与选择：** 装配树状态和零件高亮实时同步。
- **其他视图设置：** 模型校正、剖切状态及预设、灯光和动画按相应工具说明同步。

![主持人隐藏一个零件](manual-shots/08-part-toggle.png)

![访客同步看到该零件已隐藏](manual-shots/09-guest-part-sync.png)

> 应用把模型传到访客浏览器内存中显示，不主动将模型保存为磁盘文件。关闭页面后不再显示模型，但这不是防复制措施，请仅向有权查看模型的人分享。

<a id="section-15"></a>
## 15. 会话聊天

每个会话都有内置聊天窗口，创建或加入会话时自动打开，方便边看模型边讨论。

![会话聊天窗口](manual-shots/21-chat.png)

### 发送消息

- 在底部输入框输入消息，按 **Enter** 或点击 **Send（发送）**。
- 每条消息显示发送者姓名、内容及时间，自己的消息以绿色突出显示。
- 点击 **✕** 关闭窗口；通过会话面板的 **Chat（聊天）** 按钮重新打开。
- 可通过零件右键菜单 **Comment…** 发送附带零件名称的评论。

### 聊天记录

服务器最多保留 200 条消息，并把保留的记录发送给后来加入者。

点击聊天窗口标题栏的 **⬇** 可将记录下载为 `.txt` 文件，文件名为 `chat-<session-code>-<date>.txt`。每行采用 `HH:MM  name: message` 格式，文件头记录生成时间。

<a id="section-16"></a>
## 16. 离开会话

点击 **Leave session（离开会话）**：

- **访客离开：** 共享模型从该访客视图中清除，返回空白查看器；其他成员的会话继续。
- **主持人离开：** 主持人保留本地模型并回到单人查看模式，但其他成员的会话结束，访客模型被清除，并显示 **host left — session ended（主持人已离开，会话结束）**。关闭主持人的浏览器也会结束会话，不会自动转交主持权。

![离开会话后的视图](manual-shots/10-after-leave.png)

## 17. 打开 STEP / IGES / STL 文件

内置转换通过本机 OpenCascade 内核处理 STEP、IGES 和 STL。打开时显示转换进度，完成后加载 GLB；支持的源文件颜色和材质会保留，零件名称显示在装配树中。

![STEP 文件转换为 GLB 的过程](manual-shots/11-step-converting.png)

当前服务器启动时要求 OCP 可用。如提示本机后端不可用，请将 `CAD_PYTHON` 指向能够成功执行 `import OCP` 的 Python 环境，再重新启动。便携版应完整解压并保留随包提供的运行环境目录。

<a id="section-18"></a>
## 18. 独立离线 CAD 转换工具

除了查看器自身的转换功能，另一个独立项目 **CAD Converter** 提供 `convert-cad` 工具（英文手册介绍版本为 v0.26），可在不运行查看器的情况下把 STEP/IGES/STL 转成 GLB/GLTF。它与本查看器的内置转换器独立，需另行取得该项目。

如果希望先离线转换或优化模型，再打开或共享，可选择以下版本：

| 版本 | 类型 | 用途 |
|---|---|---|
| **CAD Converter（`convert-cad`）** | 浏览器界面工具 | 拖放转换、预览，以及可选的 Draco 压缩 |
| **CAD Converter2** | 桌面工具 | 在本机桌面应用中离线转换和优化 |

先生成 GLB/GLTF，查看会话中便无须再次执行 CAD 转换。网页工具提供 **Draco** 选项；应比较实际输出大小，因为它通常更适合密集网格，并非对每个多零件装配都能减小文件。

### 输入与输出

| 输入 | 说明 |
|---|---|
| `.step`、`.stp` | 边界表示（B-rep）；保留装配零件名称和逐零件颜色 |
| `.igs`、`.iges` | 边界表示；保留颜色，零件命名为 `Part1..N` |
| `.stl` | 网格；英文手册介绍的独立工具使用主机端纯 JavaScript 写入器转换 |

输出格式由扩展名决定：`.glb` 是单个二进制文件；`.gltf` 是 JSON 文本并附带 `.bin` 文件。

### 使用拖放网页界面

1. 在独立 CAD Converter 项目中双击 **`convert-cad-web.bat`**，或运行 `node convert-cad-server.mjs`。
2. 在浏览器中打开 **<http://localhost:8787/>**。
3. 将 STEP/IGES/STL 文件拖放到页面中。
4. 选择 **.glb** 或 **.gltf**，点击 **Convert（转换）**。
5. 在内置三维视图中预览：拖动旋转、滚轮缩放、右键拖动平移；随后点击 **Download（下载）**。

![独立转换工具的拖放网页界面及模型预览](manual-shots/16-convert-cad.png)

### 使用 CAD Converter2 桌面工具

启动其便携桌面程序，选择 STEP/IGES/STL 文件，设置输出格式及优化或压缩选项，然后点击 **Convert**。桌面工具显示零件数量、面数减少情况、输出大小、处理时间，以及装配树和三维预览。

![CAD Converter2 桌面工具的统计信息、装配树和预览](manual-shots/17-cad-converter2.png)

### 命令行

在独立 CAD Converter 项目目录中执行：

```bash
node convert-cad.mjs input.step output.glb
```

### 运行要求

独立转换器使用本机 OpenCascade/OCP 7.9.3。按该工具的配置要求，将 `CAD_PYTHON` 指向可以成功执行 `import OCP` 的 Python 环境；Node 启动器需要 Node.js。

### 对共享的帮助

一次转换得到 GLB/GLTF 后，即可将该文件交给其他人直接在查看器中打开，无须在查看时再次转换。独立转换工具的运行要求与查看器服务器的启动要求应分别配置。

<a id="section-19"></a>
## 19. 常见问题排查

| 问题 | 处理方法 |
|---|---|
| 另一台电脑无法打开应用 | 使用主持人提供的局域网加入链接，确认两台电脑在同一网络，且防火墙允许应用使用的端口（默认 8088） |
| STEP/IGES/STL 转换失败或服务器提示 OCP 不可用 | 将 `CAD_PYTHON` 指向能够成功执行 `import OCP` 的环境，然后重启；便携版先确认已完整解压 |
| 访客看不到模型 | 主持人必须保持连接并加载或共享模型；空会话需要等待主持人共享 |
| 端口已被占用 | 使用 `start.bat 4323`，或在 `port.txt` 中写入 `4323`；注意便携版的 `port.txt` 会覆盖启动参数 |
| 加入链接中的 IP 不正确 | 检查服务器电脑的局域网地址，刷新或重新创建会话以重新检测 |
| 测量不能吸附 | 确认已启用 Measure，并将鼠标靠近角点，而不是平面中央 |
| 爆炸视图看起来像整个模型一起移动 | 在零件树中选择包含多个直接子项的装配，检查 Scope 和 Dir；只有一个子装配的顶层节点可能作为整体移动。旧版若提供 Level，可选择 All parts |
| 启动后浏览器暂时打不开页面 | 保持启动窗口运行，等待服务器完成启动后刷新，并检查实际端口和窗口中的错误信息 |
| 没有中文界面选项 | 检查是否提供有效的外部中文语言包；本中文手册不会自动安装界面语言包 |

<a id="section-20"></a>
## 20. 与外部人员共享

本应用默认用于可信的**局域网（LAN）或受控网络**。如需让网络外的人员加入，英文手册介绍了以下两种部署方式。

### 方式一：路由器端口转发

1. 查找服务器电脑的局域网 IP，例如 `192.168.x.x`。
2. 在路由器管理页面中，把应用端口（默认 8088）转发到该电脑的对应 IP 和端口。
3. 将 `http://<公网-IP>:8088` 地址提供给外部人员。

公网 IP 可能变化。开放端口会把服务暴露到互联网，应结合适当的访问控制，临时使用后关闭转发。正式部署应使用 HTTPS，例如通过支持 TLS 的反向代理提供服务。

### 方式二：部署到公共或虚拟服务器

1. 准备具有公网 IP 或域名的虚拟服务器。
2. 部署应用和适用的依赖及本机 CAD 运行环境。从源代码目录运行时使用 `node src/server.js`；便携包目录结构不同，应使用对应启动器。
3. 将部署后的服务器地址提供给外部人员。

这种方式适合需要持续在线的演示或供应商协作，不依赖家用路由器和个人电脑长期运行。

> **访问控制：** 能够访问服务器的人可能可以加入或操作共享会话。模型传到浏览器内存并不构成防复制保证。敏感模型应只向授权人员共享，并使用适当的网络访问控制；可考虑私有网络或 VPN。部署说明见 [安全政策](../SECURITY.md)。
